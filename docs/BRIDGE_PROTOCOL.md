Host (WPF + WebView2) <-> UI message protocol. Transport: UI posts a JSON
string via `window.chrome.webview.postMessage`; host replies with
`PostWebMessageAsJson`. Max message size: 1 MB. File bytes never cross
the bridge; previews use `https://cache.appassets.example` URLs.

## Envelope (JSON, camelCase, enums as strings)

```json
{ "v": 1, "id": "uuid", "type": "req|res|evt|cancel",
  "method": "nodes.list", "params": {},
  "result": {}, "error": { "code": "NOT_FOUND", "message": "dev-only English text",
                           "retryable": false, "details": {} } }
```

- Handshake: `app.hello` returns `{ contract: { major, minor }, hostVersion,
  capabilities[], features{}, settingsSnapshot, uiStatus }`. Compatible when the
  major matches and host minor >= UI minor.
- Cancellation: `{ type: "cancel", id }` aborts the in-flight request.
- Pagination: opaque `cursor` + `limit` (default 200).
- Mutations accept `idempotencyKey`; destructive ones need a `confirmationToken`.
- Events are coalesced (>= 100 ms per topic). Errors cross as codes only;
  `message` is developer English; the UI localizes by code.
